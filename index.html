Cài đặt Gemini

Cách giữ key
🛡 Khoá key để người khác lấy được cũng không dùng được
  1. Mở Google Cloud Console → Credentials, chọn project của key Gemini.
  2. Bấm vào key → Application restrictions: chọn Websites, thêm địa chỉ trang này (ví dụ https://tên-bạn.github.io/*).
  3. API restrictions: chọn Restrict key → chỉ tick Generative Language API. Lưu lại.
  4. Trong AI Studio nên dùng gói miễn phí hoặc đặt giới hạn chi tiêu để không bị tính tiền bất ngờ.

🔒 Mở khoá API key

Nhập mã PIN bạn đã đặt để dùng Gemini trong tab này.
